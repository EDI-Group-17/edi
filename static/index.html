A Dynamic Risk-Aware Security Framework for MCP

AgentShield operates as a Transparent Proxy that sits directly between an AI Client (like Claude or Cursor) and a Company's MCP Server. It intercepts raw JSON-RPC traffic to actively block Prompt Injections, prevent Destructive Actions via Human-in-the-Loop (HITL), and dynamically Redact Sensitive PII Data.

1️⃣ How Deployment Works

AgentShield requires Zero Code Changes to the AI or the target MCP server. You simply configure your AI to point to http://localhost:8000/proxy instead of the real server. The AI thinks it's talking to the target, and the target thinks it's talking to the AI.

2️⃣ The Inspection Pipeline

When a JSON payload arrives, AgentShield uses a 3-Tier engine:

  • Regex Engine: Scans strings for anomalies and overrides.
  • Heuristic Engine: Analyzes tool semantics for high-risk flags (e.g. `delete_repo`).
  • Sanitizer: Recursively checks inbound responses for PAN, Aadhaar, and API keys.
